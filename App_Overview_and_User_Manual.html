Application OverviewWhat this app does & who it serves

The Venkateshwara UPVC Quotation Maker is a full-stack cross-platform business application that digitizes the entire quotation workflow for a UPVC windows and doors business. It replaces manual paper-based quotation creation with a complete digital system.

What It Handles

The application covers the complete workflow — from the first customer call, through site measurement, quotation generation, client approval, and final installation billing:

  • Customer data management with intelligent autocomplete
  • Precise measurement calculations (MM to Square Feet)
  • Automatic price computation with configurable GST
  • Professional PDF generation with full company branding
  • Email delivery of quotations directly to customers
  • Cloud database storage with automatic save
  • Business analytics and revenue tracking

Input → State Update → Auto-save (2s debounce)
                      → Supabase API → PostgreSQL
                      → PDF Generator → File/Share/Email
                      → Brevo SMTP → Customer Inbox

Why This Architecture?

  • Separation of concerns: UI, state, and services are independent — changes in one don't affect others
  • Testability: Each layer can be tested in isolation
  • Scalability: Supabase PostgreSQL handles growth without migration
  • Offline resilience: Auto-save with debounce ensures no data loss
  • Cross-platform: One codebase, 6 platforms — not 6 separate projects

Stored Procedure: get_next_quote_number()

A PostgreSQL function that atomically increments and returns the next sequential quote number. This ensures no duplicates even if two quotations are created at the exact same moment — a detail many "simple database connections" fail to handle.

User ManualComplete step-by-step guide

6.1 Getting Started

1

Login

Open the app. Enter your email and password. Tap Login or press Enter on your keyboard.

2

First Time? Set Your Password

Tap "Forgot Password?" — a 6-digit OTP will be sent to your registered email. Enter the OTP in the app, then create a new password (minimum 6 characters).

3

Dashboard Overview

After login you'll see your dashboard with: quick action cards (New Quotation, Send Email), search bar, filter options, quotation list, and side navigation menu.

6.2 Creating a Quotation

1

Start a New Quotation

Tap "New Quotation" from the dashboard card, side menu, or floating action button (+). The quote number and date are auto-generated.

2

Enter Customer Details

Name: Start typing — past customers appear as suggestions. Select one to auto-fill address, contact, and email.
Reference: Project name (optional).
Address: Installation site address.
Contact No: 10-digit phone number.
Email: For sending the quotation PDF.

Use Tab or Enter to quickly move between fields — keyboard navigation is fully supported.
3

Add Measured Items

Tap "Add Measured Item" for each window or door with specific dimensions:

Code (e.g., W1, D2) · Description (e.g., "Sliding Window 4ft x 4ft") · W (MM) · H (MM) · Units · Glass type · Rate (Rs) per sq.ft.

The app automatically calculates: Sq.Ft. = (W/304.8) × (H/304.8) × Units, then Total = Sq.Ft. × Rate.

4

Add Unmeasured Items

For flat-rate items (hinges, handles, installation charges), tap "Add Unmeasured Item" and enter description, units, and rate. Total is auto-calculated.

5

Finalize & Generate

Add Transport Cost if applicable. Toggle GST on/off and adjust the percentage. The app shows subtotal, tax, and grand total in real time — including the amount spelled out in words. Tap "GENERATE PDF" when ready.

6.3 Managing Quotations

1

Search & Filter

Type in the search bar to find quotations by customer name or quote number. Use the filter icon to sort by newest, oldest, highest amount, or lowest amount.

2

Edit a Quotation

Tap any quotation card on the dashboard to open it in edit mode. Changes auto-save to the cloud after 2 seconds of inactivity.

3

Share or Email PDF

After generating PDF, you can open it, share via any app (WhatsApp, email), or send directly to the customer's email. The email includes a professional HTML template with the company logo.

6.4 Settings

1

Configure Company Info

Access from the side menu → Settings. Edit company name, address, contact, proprietor name, GST number, bank details, terms & conditions, and default GST percentage. All changes reflect immediately on new quotations.

2

Toggle Dark Mode

Switch between light and dark themes from Settings. Your preference is saved and persists between sessions.

Security & Data HandlingEnterprise-grade protection

ConcernHow It's Handled
Password StorageSHA-256 hashed — never stored in plain text. Even database access can't reveal passwords.
Session ManagementEncrypted local storage via platform Keystore / Credential Manager. Survives app restarts.
Data in TransitAll Supabase traffic over HTTPS TLS 1.3. SMTP over STARTTLS.
Database AccessRow-Level Security (RLS) policies on every table. No anonymous access.
API KeysAnon key restricted by RLS. Service role key never in client code.
Environment VariablesSMTP key stored in .env file, excluded from version control.
Input ValidationClient-side type checking, length limits on phone numbers, format validation on email.
Error HandlingEvery API call, database operation, and file operation wrapped in try-catch. No silent failures.
