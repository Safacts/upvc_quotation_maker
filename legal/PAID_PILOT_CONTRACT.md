## 3. Supported pilot workflow

The supported journey is browser-based and online:

1. An authenticated user signs in.
2. The user creates or selects a customer.
3. The user enters dimensions and pricing.
4. The user saves a quotation.
5. The user generates a branded PDF.
6. The user uses the supported share/portal action.
7. The system records the server-derived response/status and follow-up.

A **customer-ready quotation** means a persisted, tenant-owned quotation with correct totals, quotation number, customer identity, branded PDF output, and an auditable share event. A page view, download, or client-side status change is not an approval. “Shared” means the supported system action is recorded; it does not guarantee WhatsApp or other third-party delivery.
