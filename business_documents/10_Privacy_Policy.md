## 4. DATA STORAGE & SECURITY

### 4.1 Where Your Data Is Stored

| Component | Provider | Location |
|-----------|----------|----------|
| **Database** | Supabase (PostgreSQL) | Tokyo, Japan (production) / Mumbai, India (staging) |
| **Application Hosting** | Vercel | Global edge network |
| **Email Delivery** | Brevo (Sendinblue) | France |
| **File Storage** | Supabase Storage | Same region as database |

### 4.2 Security Measures

Vitharn implements the following security measures:

1. **Row-Level Security (RLS):** Each client's data is strictly isolated. No client can access another client's data.
2. **Encrypted Passwords:** All passwords are hashed using bcrypt. We never store plaintext passwords.
3. **HTTPS Encryption:** All data in transit is encrypted using TLS 1.2+.
4. **HttpOnly Session Cookies:** Session tokens are stored in secure, HttpOnly cookies to prevent XSS attacks.
5. **Tenant Isolation:** Every database query is scoped to the authenticated client's tenant ID.
6. **Regular Security Audits:** Bugsy (our QA agent) conducts regular security audits to identify and fix vulnerabilities.

### 4.3 Data Retention

| Data Type | Retention Period |
|-----------|------------------|
| **Active account data** | Indefinitely (while account is active) |
| **Deleted data** | Soft-deleted for 30 days, then permanently purged |
| **Account data after cancellation** | 30 days after notice period, then permanently deleted |
| **Backup data** | Rotated automatically; oldest backup retained per tier (7–30 days) |
| **Support tickets** | 12 months after resolution |
| **Usage logs** | 90 days (anonymised) |
